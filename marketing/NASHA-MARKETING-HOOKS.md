| Hook | Seed content | Honest constraint |
|---|---|---|
| "Two kitchens, one table" | Short pieces on one Crossing theme (chile, fermentation, flatbread) | Use only audited wording (`research/HISTORICAL-CLAIMS-AUDIT.md`); label Analogy vs Supported |
| "Designed, not yet cooked" | Publish a dish spec, then the first test result, failure included | Publish only real tests; no staged food photos; never backdate |

| "Build in public: Labs" | Monthly log of decisions and what changed | Follow `website/data/labs.json` method rules |
| "Pop-up announcement" | Only when a real event is permitted and scheduled | Permits first; alcohol rules |

**Do not:** buy ads, use influencers, post testimonials, show invented guests, imply a brewery exists, or use "Best" claims. **Metric rule:** counts of followers are not validation; use `validation/TRACTION-METRICS.md` events.
