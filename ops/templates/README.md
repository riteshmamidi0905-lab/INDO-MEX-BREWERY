# NASHA operating templates (header-only)
Every file here is a BLANK, founder-controlled template. No row is a real quote, contact, competitor observation or assumption until a person records it with a source and an evidence tier.
Rules: never invent supplier prices or quotes; never populate fake contacts; competitor data is real public data only with a source URL and access date; do not contact any vendor without founder authorization.
Files: capex-quotes.csv, vendor-rfq-comparison.csv, austin-competitors.csv, founder-crm.csv, dataset-provenance.csv. Finance inputs live in ops/finance/assumptions.csv. Sales for menu engineering: ops/menu-engineering/sales.csv.
