# NASHA Website Design System and Technical Decision

**Status:** `[DESIGN]` for a **prototype that works locally**. It is not deployed, has no domain, and publishes nothing commercial. Name status: `SELECTED_BY_FOUNDER — LEGAL CLEARANCE PENDING` (D-62). Decision record: D-63.

## 1. Technology (D-63)
Static HTML, CSS and a small vanilla JS file, generated by a Python stdlib script (`website/build.py`) from audited content in `website/data/*.json`. Output is committed in `website/dist/`. **No framework, bundler, package manager at runtime, CDN, tracker or third-party script.** Chosen because the site is content-light, must be fast and accessible, must be understandable by a non-engineer founder, and every asset must be rights-registered. Revisit if a CMS, ordering, bookings or accounts are needed (not now). Hosting is undecided; any static host works. Pages are `noindex` until launch is decided.

## 2. Tokens (`website/src/styles.css`)
Colour (proposed, `brand/NASHA-IDENTITY-SYSTEM.md` §3): Soot, Char, Bone, Marigold (the one accent; **never text on light, use Marigold-ink**), Limestone, Indigo for the hero/crossing bands, Straw as accent on dark. Type: Instrument Serif (display) and Inter variable (text), self-hosted under OFL, latin only. Spacing scale `--s-1…--s-9`; measure 62ch; wrap 72rem. Dark by default, light by system preference or a toggle remembered per viewer.

## 3. Components
Header with skip link and wordmark (typographic placeholder, no logo designed); nav; hero with disclosure; eyebrow + beat number; statement; card; chip; heat dots (with text alternative); dish card; beer card with glass icon; filter group (progressive enhancement); Crossing row; status/path list; indigo band; footer with the name notice, meaning, allergy and responsible-drinking text.

## 4. Behaviour
Works without JavaScript (all dishes and beers visible, filters absent). JS only adds: theme toggle, and filters that announce counts with `aria-live`. Motion: slow glow and steam in the hero, disabled under `prefers-reduced-motion`.

## 5. Content rules
No present-tense operating claims, no commerce, no halal wording, no ™/®, no testimonials, no invented numbers. Dishes carry honesty labels (Fusion / Our own dish / Inspired by) and statuses (Designing/Concept); heat and vegetarian are "as designed". No ABV. Empty states are honest (Labs has no entries; updates not live). Enforced by `tools/validate_site.py`.

## 6. Quality gates (measured, `website/qa/results/latest.json`)
Real Chromium run via `playwright-core`: axe-core (WCAG 2.0/2.1/2.2 A/AA + best practice) in dark and light on all pages; horizontal overflow at 320, 390, 768, 1280, 1440, 1920 px; page weight; CLS and LCP (local server, so network is not representative); no-JS render; reduced-motion; filter interaction; skip link first tab. Automated checks cannot prove accessibility: a manual screen-reader and keyboard pass is still owed. **Run:** `python3 website/build.py && cd website/qa && npm i && node run-qa.mjs`, then `python3 tools/validate_repo.py`.

## 7. Performance budgets
HTML+CSS+JS ≤ 150 KB per page; fonts ≤ 200 KB; CLS ≤ 0.1; LCP ≤ 2.5 s (local). No images means the budget is dominated by fonts.

## 8. Rights
`ip/website-asset-rights-register.csv` is regenerated from `dist/` by the build; the validator fails if any shipped file is missing. AI-assisted authorship is declared.

## 9. Accessibility review record (Sprint 8; what was and was not done)
**Automated (real Chromium, `website/qa/run-qa.mjs`):** axe-core WCAG 2.0/2.1/2.2 A and AA plus best practice, dark and light, all 8 pages: 0 violations. **Keyboard:** first Tab stop is the skip link; every focusable element on every page (12-25 per page) shows a visible outline of at least 2 px when focused; filters, Two-Pour and beer swatches are native buttons/inputs. **Zoom/reflow:** no horizontal scroll at 320 px (400%) or 640 px (200%) on any page; WCAG 1.4.12 text-spacing override causes no overflow. **Images off:** alt text present on every image and layout holds. **JS off:** pages render fully (filters and swatches absent, all content visible). **Reduced motion:** animation static.
**Manual contrast review (computed, because axe cannot measure text over SVG patterns):** bone text on the indigo/lattice bands is at worst 7.3:1 against the lattice line colour and 13.3:1 on plain indigo; straw accent text is 5.1:1 on the lattice line and 9.4:1 on indigo; zone diagram labels are 5.6:1 or better; image tags are 16:1. axe still lists these as "needs review" for the lattice bands and the zone diagram because it cannot evaluate overlaid SVG.
**NOT performed:** screen-reader testing (NVDA/JAWS/VoiceOver), real-device testing, real-network testing. Do not claim them.

## 10. Sprint 7 additions
- **Pages:** Experience, Space added; Home rebuilt as ten beats; Food, Beer, The Crossing rebuilt editorially; Labs shows the pop-up illustration.
- **Image pipeline** (`website/images.py`): desktop and mobile (4:5) compositions per raster, AVIF + WebP + JPEG fallback, 480-1920 px widths, explicit dimensions, lazy loading except the preloaded hero. Sources live in `visuals/web-source/`; the canonical list is `visuals/NASHA-VISUAL-MANIFEST.csv`. A manifest row with a raster source becomes a `<picture>`; otherwise a drawn illustration (`website/art.py`) stands in.
- **Labels:** each figure carries a small corner tag, "Concept visualization" or "Concept illustration".
- **Rights:** AI-made rasters are `PROVISIONAL-LOCAL-ONLY`; the validator keeps every page `noindex` while any exist.
- **Logo protection (D-66):** the NASHA lettering is a disclosed temporary typographic placeholder; the favicon is empty; `dist/` may contain only web assets; nothing from `brand/logo/` is ever read.
- **Motion:** flame flicker, rising bubbles, reveal-on-scroll, Two-Pour steps and beer-colour preview; all static under `prefers-reduced-motion`.
- **QA additions:** slow-connection profile, image-failure test, stale-QA hash check, home initial-transfer budget (450 KB).

## 11. Sprint 8 additions
