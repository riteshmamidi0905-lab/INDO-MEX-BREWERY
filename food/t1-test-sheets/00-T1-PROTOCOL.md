# T1 Protocol (applies to every T1 test sheet)

**Status:** methodology only. **No test has been run and no result exists.** Fields stay blank until real testing. Policy: no beef, no pork (D-54); not claimed halal.

## 1. Before any cooking
1. Fill the **policy and ingredient screen** (D-54): every ingredient label photographed; lard, meat stock, gelatin and rennet statements requested from suppliers; unknowns recorded as "unknown", never assumed compliant.
2. Write the **decision rule** (sheet §9b) before cooking, so results cannot move the goalposts.
3. Assign roles: cook, recorder, photographer, tasters (≥ 5; ≥ 2 with each cuisine background where possible; advisors when available `[PRO]`).
4. Calibrate: thermometers, scale (0.1 g), timer; record fryer/oven set points.

## 2. Variables and controls
Change **one variable per iteration**; keep a control for comparison; minimum **3 iterations**; record raw weights, times, temperatures (do not infer). Replicate any surprising result.

## 3. Tasting rules (bias control)
Blind and randomised where practical (coded plates); water and plain cracker between samples; tasters score before discussion; do not tell tasters the hypothesis; record dissent verbatim; the cook does not score their own dish.

## 4. Common rubric (0-5 unless stated; write the anchor words you used)
| Attribute | 0 | 3 | 5 |
|---|---|---|---|
| Flavour/balance | unpleasant/unbalanced | acceptable, one dimension dominates | balanced, layered, finishes well |
| Aroma | none/off | present, generic | distinct, appetising |
| Texture | fails (rubbery, soggy, dry) | acceptable | exactly right for the dish |
| Temperature | wrong | acceptable | ideal at service |
| Structural integrity | collapses/leaks | holds with care | holds through eating |
| Portion/visual | unappealing | fine | would be photographed |
| Inspiration clarity ("I can tell what each tradition contributed") | none | partial | clear to a specialist of each tradition |
| Indo-Mex integration ("it feels like one dish, not two") | two dishes stuck together | partly integrated | seamless and sensible |
| Craveability ("I want another bite") | no | maybe | yes |
| Beer pairing potential | clashes | neutral | clearly improves with a named beer |
Also record (cook): prep complexity (1-5), service complexity (1-5), holding performance (minutes of acceptable quality), consistency across iterations (same/different and how), ingredient availability (1-5 with supplier names), waste (g and cause), approximate yield (cooked g / raw g), repeatability (could a second cook reproduce it from the card? y/n), major failure modes (free text).

## 5. Decision outcomes
KEEP (meets pre-set rule in 2 of 3 iterations) · REWORK (state the single next change) · HOLD (needs equipment/supplier/professional input) · CUT (fails twice; reason recorded; dish stays in the pool, not deleted).

## 6. Data handling
Photos named per sheet §11; scores transcribed from paper to the sheet within a day; **no synthetic or imagined results**; if an iteration is skipped, leave it blank.
